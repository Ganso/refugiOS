# Compatibility Table

This document details the compatibility status of **refugiOS** with different operating systems and hardware architectures.

> [!TIP]
> The **pre-built image** of refugiOS (downloadable from [refugios.ganso.org](https://refugios.ganso.org/)) is based on Debian Trixie with XFCE and is the easiest way to get started on PC. It does not require prior installation of the base operating system.

## x86 Architecture (PC / Laptop)

| Operating System / Method | Status | Notes |
| :--- | :--- | :--- |
| **Pre-built image (Debian Trixie)** | ✅ Certified | Recommended method. Direct download from [refugios.ganso.org](https://refugios.ganso.org/) |
| **XUbuntu 24.04 LTS** | ✅ Certified | Alternative method (Live with persistence) |
| **Xubuntu 25.10** | ✅ Certified | Must be retested for every new release |
| **Debian 11 (Bullseye)**| ⚠️ Issues | Requires adjustments. See [Technical Details](#debian-11-bullseye) |
| **Other distros (Debian/Ubuntu)** | 🧪 Untested | Testers wanted |

## 🧪 Detailed Testing and Known Issues

### Debian 11 (Bullseye)
Installation has been tested on Debian 11, but several issues have been identified that require manual intervention or future correction:

*   **Flatpak:** The Flatpak package might not be installed automatically during the initial setup process.
*   **AppImages:** Errors have been reported regarding the dependencies required to run some AppImages.
*   **Issue Tracking:** These bugs are being tracked in **[Bug #10](https://github.com/Ganso/refugiOS/issues/10)** of the distribution.

### Native System Image (build_refugios.sh)

The base image generated by `scripts/build_refugios.sh` requires no post-install manual steps for desktop icons. Launchers are automatically marked as trusted by XFCE on first login via the `metadata::xfce-exe-checksum` GIO metadata mechanism (requires `libglib2.0-bin`, included in the image).

### Graphics Acceleration and NVIDIA GPUs

The base refugiOS image includes open-source drivers and standard firmware (`amdgpu`, `intel`, `nouveau`) to ensure universal compatibility and seamless booting across virtual machines (QEMU, VirtualBox) as well as Intel and AMD systems. If the system features an NVIDIA GPU, the installer (`install.py`) detects the card and offers to install official proprietary drivers (`nvidia-driver`) to enable CUDA hardware acceleration for local AI models.
